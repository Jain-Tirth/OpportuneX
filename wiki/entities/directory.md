# Entities Directory

This directory maps the schema and definitions of the primary data entities stored within the Supabase database.

---

## 1. Event Entity (`Event` table)

This table stores all aggregated opportunities scraped from Unstop, Devfolio, Devpost, and Eventbrite.

| Column Name | Database Type | Description |
| :--- | :--- | :--- |
| **id** | `integer` (Primary Key) | Auto-incrementing identifier. |
| **title** | `text` (Required) | The name of the event. |
| **description**| `text` | Detailed information about the event. |
| **type** | `text` | E.g. `hackathon`, `competition`, `workshop`. |
| **startDate** | `date` | Event start date. |
| **endDate** | `date` | Event end date. |
| **deadline** | `date` | Registration submission deadline. |
| **tags** | `text[]` (Array) | Associated technology keywords. |
| **hostedBy** | `text` | Platform host name (e.g. `devfolio`). |
| **verified** | `boolean` (Default: `false`) | Set to `true` if manually verified. |
| **redirectURL**| `text` | Web address to view and register. |
| **embedding** | `vector(384)` | 384-dim floating point query vector. |

---

## 2. Saved Events Entity (`saved_events` table)

This table manages user bookmarks for events.

| Column Name | Database Type | Description |
| :--- | :--- | :--- |
| **id** | `integer` or `uuid` (PK) | Row identifier. |
| **user_id** | `uuid` (Foreign Key) | Supabase Auth user identification. |
| **event_key** | `text` | Unique key string generated by client to identify the event. |
| **event** | `jsonb` | Full snapshot of the matching `Event` object. |
| **created_at** | `timestamp` | Bookmark timestamp. |

### Event Key Generator
To maintain bookmarks across platforms, the client generates a unique string identifier via `getEventKey(event)`:
1. Returns `id:{event.id}` if a database row ID is present.
2. Returns `url:{event.redirectURL}` if a link is present.
3. Fallback: `title:{title}|{hostedBy}`.
